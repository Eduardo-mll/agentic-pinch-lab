# Pinch Analysis and delta_t_min (local approved note)

Classical Pinch Analysis uses a minimum temperature approach (`delta_t_min`)
when constructing composite curves and utility targets.

Qualitative engineering expectation:

- Smaller `delta_t_min` usually increases the maximum process heat recovery
  and can reduce external heating/cooling targets.
- Smaller `delta_t_min` usually increases required heat-exchanger area and capital cost.

For this hackathon MVP we only test the energy-target direction with a
deterministic computational experiment. Economic trade-offs are Phase 2.

This file is a local approved evidence source for the Evidence Agent cache.
It is not a substitute for peer-reviewed literature in a full study.
